AI Opportunity Atlas — data

500 scored AI startup niches plus the Y Combinator AI landscape they were derived from. Snapshot 2026-08-24. Everything on this site is plain HTML so any AI assistant or scraper can read it directly.

Reading this with an AI assistant? Give it these page URLs directly — tested and read in full. English: method.html, then niches-1.html … niches-6.html, then landscape.html. 繁體中文: method-zh.html, then niches-zh-1.html … niches-zh-7.html, then landscape-zh.html. Each page is ~45KB and contains its data as a CSV block.

There are also single-page versions (all.html / all-zh.html) with everything at once — convenient for humans, but at ~350KB an AI browser will usually truncate the end, so prefer the split pages for analysis.
All pages: Open these pages in order: method.html (how to read the scores), then niches-1.html through niches-6.html (all 500 niches), then landscape.html (the YC company data). Every page contains the data twice — as an HTML table and as a CSV block — so either parsing route works.
